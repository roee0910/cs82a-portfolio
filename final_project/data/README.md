# Data files

The original Kaggle competition data are not committed here. Download `train.csv` and `test.csv` from the [House Prices: Advanced Regression Techniques data page](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data) after accepting Kaggle's applicable competition terms, then place them in this folder. Keep `data/*.csv` and `data_description.txt` out of public version control unless Kaggle's current terms explicitly permit redistribution.
